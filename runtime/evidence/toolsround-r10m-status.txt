Track C1-C3 acceptance round for HarnessToolsR10M:jbfly -- 2026-08-03
=====================================================================

RESULT: build + install proven on an isolated emulator instance, and every
system call the three new ops (battery, store_info, pkg_list) make was proven
on the real ROM by evaluating their expressions with runtime/ns_eval.py --
see toolsround-r10m-nseval.txt for the values returned. What remains unproven
is only the TRANSPORT: the ops have never travelled the /tools long-poll,
because the broker address is host-side and human-gated.

-------------

   examples/harness-tools/harness-tools.nprj:8.

       /packages/harness-tools/harness-tools.pkg 'HarnessToolsR10M:jbfly'
     -> "queued" / "queued"; a second attempt returned the Newton notification

Why the ops were not exercised over the /tools link
---------------------------------------------------
a) HOST ADDRESS MISSING (the hard blocker).
   examples/harness-tools/Main.newt:72 hardcodes the broker at 10.42.0.1:18081
   with no runtime override, and runtime/raw_pkg_server.py binds that literal
   address. `ip addr show lo | grep 10.42.0.1` returned nothing for the entire
   session. Adding it requires `sudo ap/emulator-only.sh`; the installed sudoers
   rules cover only apply.sh and teardown.sh, so an agent cannot bring it up.
   Polled every 30 s for 20 minutes -- never appeared.

b) A FRESH INSTANCE IS NOT NETWORK-READY (a second, independent blocker found
   during the attempt; previously undocumented).
   - The blank flash boots into the first-run Welcome tour. While the tour is
     running the protoFloatNGo window does not appear even though :Open()
     returns TRUE. The tour was clicked through (name/country/address/phones/
     date/time/handwriting/signature/Done) to reach the Notepad.
   - None of the NIE stack in runtime/nie2/ is installed on a fresh flash, so
     there is no Ethernet driver and no saved Internet Setup for InetGrabLink
     to use. (InetGrabLink itself IS in the 717006 ROM:
       runtime/ns_eval.py --instance c1round "if GetGlobalFn('InetGrabLink) then \"yes\" else \"no\""
       -> "yes")
   - POST /install rejects any path outside /packages/ with HTTP 400
     (containers/patches/einstein-control-socket.patch:119-124), so the nie2
     packages had to be staged into examples/ first.
   - newtdev.pkg (Newton Device Drivers) MUST be installed before NE2K.pkg.
     Installing NE2K first produced the Newton error
       "Unable to activate NE2K since Newton Device Drivers are not in the system"
     and after a container restart, boot error (-48807).
